# 🍽️ Eat Today  
**"What are we going to eat today?"**  
A simple and fun Flutter app to help you decide your daily meals — no more wasting time thinking!

---

## 🗃️ Tech Stack

- 💙 **Flutter** – for a smooth cross-platform experience  
- 🗄️ **SQLite (Local Database)** – to store your meals offline  
- 💡 Simple logic, user-friendly interface, and clean design

## 🔥 Features

- 📝 Add and manage meals in a local database  
- 🎲 Get a random meal suggestion with one click  
- ❤️ Mark your favorite meals  
- 🧠 Simple UI/UX — anyone can use it
